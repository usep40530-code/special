HAPPY BOYFRIEND DAY ❤️ - VS CODE PROJECT

1. Extract the ZIP and open the folder in VS Code.
2. Open index.html with Live Server or in your browser.
3. In index.html find:
   const CORRECT_NAME = "YOUR NAME";
   Replace YOUR NAME with your boyfriend's name.

PHOTOS:
Put your photos in this same folder:
photo1.jpg
photo2.jpg
photo3.jpg
photo4.jpg
photo5.jpg
photo6.jpg

MUSIC:
Put your song in this folder as:
song.mp3

EDIT:
You can directly change the love letter, reasons, timeline, and final message in index.html.

The website includes:
Name screen -> animated envelope -> Happy Boyfriend Day reveal -> love letter -> photo memories -> reasons -> timeline -> final surprise/confetti -> music.
